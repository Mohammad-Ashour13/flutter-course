# الجلسة الثانية: أساسيات لغة Dart

## معلومات الجلسة

- المدة المقترحة: 180 دقيقة لأن المصدر يجمع أفكارًا كثيرة.
- بيئة التنفيذ: DartPad أو ملف Dart عادي.
- المشروع الناتج: برنامج نصي صغير يدير درجات طلاب.
- حافظنا على ترتيب المصدر: المتغيرات، List، Map، Class، الوراثة، `final` و`const`، الشروط، الحلقات، الدوال.

## أهداف التعلّم

بنهاية الجلسة يستطيع الطالب أن:

- يخزّن قيمة في متغير ويختار نوعًا مناسبًا.
- يستخدم `List` لمجموعة مرتبة و`Map` لربط مفتاح بقيمة.
- ينشئ كائنًا بسيطًا من `class`.
- يفهم الوراثة على مستوى تمهيدي.
- يميّز بين متغير عادي و`final` و`const`.
- يكتب شرطًا وحلقة ودالة بسيطة.

ليس الهدف أن يتقن OOP والوراثة في جلسة واحدة؛ الهدف أن يتعرف إليهما ويستخدم مثالًا صغيرًا.

## القصة المستخدمة في الأمثلة

سننشئ «نادي طلاب» يحفظ:

- اسم طالب وعمره.
- قائمة هوايات.
- درجات مواد.
- كائنًا يمثل الطالب.
- قرار النجاح.
- دوال تحسب وتطبع.

استخدام قصة واحدة يقلل الحمل الذهني بدل تغيير المجال في كل مثال.

## تسلسل الشرح

### 1. المتغيرات — 25 دقيقة

ابدأ بكأس فارغ وضع عليه ملصق «الاسم». المتغير مكان له اسم ويحمل قيمة.

```dart
String studentName = 'Lina';
int age = 15;
double average = 87.5;
bool isPresent = true;
```

اشرح الأنواع من خلال سؤال:

- هل العمر نص أم عدد؟
- هل المتوسط قد يحتوي فاصلة؟
- هل الحضور له أكثر من نعم/لا؟

ثم عرّف `var`: Dart تستنتج النوع من أول قيمة. نبّه أن `var` لا يعني أن المتغير يستطيع التحول من نص إلى عدد.

### 2. القوائم `List` — 20 دقيقة

شبّهها برف كتب مرتب. لكل عنصر موقع يبدأ من الصفر.

```dart
List<String> hobbies = ['drawing', 'football'];
hobbies.add('coding');
print(hobbies[0]);
```

نفّذ خطأً مقصودًا بطلب موقع غير موجود، واسأل لماذا حدث.

### 3. الخرائط `Map` — 20 دقيقة

شبّهها بخزائن: لكل خزنة مفتاح يقود إلى قيمة.

```dart
Map<String, int> grades = {
  'math': 90,
  'science': 84,
};
print(grades['math']);
```

قارن بوضوح:

- `List`: نصل بالقيمة عن طريق موقع رقمي.
- `Map`: نصل بالقيمة عن طريق مفتاح له معنى.

### 4. الصفوف والكائنات — 30 دقيقة

ارسم قالب بسكويت وقطع بسكويت. `class` هو القالب، و`object` قطعة تم إنشاؤها منه.

ابدأ بخصائص فقط، ثم constructor، ثم method. لا تبدأ بالكود كاملًا.

```dart
class Student {
  String name;
  int age;

  Student(this.name, this.age);

  void introduce() {
    print('My name is $name and I am $age years old.');
  }
}
```

وضّح أن `this.name` تعني خاصية الكائن، وأن القيمة القادمة من الخارج توضع فيها.

### 5. الوراثة — 15 دقيقة

استخدمها كتعرّف سريع. `ClubLeader` طالب، لكنه يملك مسؤولية إضافية. كلمة `extends` تعني أن الصف الجديد يبدأ بما لدى الصف الأب ثم يضيف عليه.

لا تدخل في polymorphism أو abstract classes.

### 6. `final` و`const` — 15 دقيقة

- متغير عادي: يمكن تغيير قيمته.
- `final`: تُحدد قيمته مرة واحدة، وقد تُعرف وقت تشغيل البرنامج.
- `const`: قيمة ثابتة معروفة قبل التشغيل.

مثال مناسب:

```dart
final loginTime = DateTime.now();
const passingGrade = 60;
```

لا تقل فقط إن `final` «متغير ثابت»؛ اشرح وقت معرفة القيمة.

### 7. الشروط — 20 دقيقة

اعرض قرارًا: إذا كانت الدرجة 60 أو أكثر فالطالب ناجح، وإلا يحتاج إلى إعادة.

```dart
if (average >= passingGrade) {
  print('Passed');
} else {
  print('Needs another try');
}
```

توقف عند الفرق بين `=` و`==` وبين `>` و`>=`.

### 8. الحلقات — 20 دقيقة

اطلب من طالب أن يطبع أسماء الهوايات دون نسخ `print` عدة مرات.

```dart
for (final hobby in hobbies) {
  print(hobby);
}
```

بعد فهم الفكرة، اعرض الحلقة التقليدية و`while`. بيّن ضرورة تغيير الشرط داخل `while` لتجنب حلقة لا تنتهي.

### 9. الدوال — 25 دقيقة

شبّه الدالة بآلة:

> مدخلات → عمل → نتيجة

ابدأ بدالة لا تعيد قيمة، ثم دالة تعيد قيمة، ثم arrow function. اجعل optional parameters وanonymous functions عرضًا خفيفًا في النهاية لأنهما أصعب على المبتدئ.

## أسئلة تحقق

- لماذا لا نخزن جميع القيم على شكل `String`؟
- متى نستخدم `List` ومتى `Map`؟
- ما الفرق بين `class` وobject؟
- لماذا يصلح `DateTime.now()` مع `final` ولا يصلح عادةً مع `const`؟
- ما الفرق بين الطباعة و`return`؟

## أخطاء متوقعة

| الخطأ | التفسير المبسط |
|---|---|
| نسيان `;` | معظم تعليمات Dart تنتهي بفاصلة منقوطة |
| استخدام اقتباسات غير متطابقة | النص يجب أن يبدأ وينتهي بالنوع نفسه من الاقتباس |
| موقع List غير موجود | العد يبدأ من 0 وآخر موقع أقل من `length` بواحد |
| نتيجة Map هي `null` | المفتاح غير موجود أو مكتوب بشكل مختلف |
| خلط class بالكائن | الصف قالب، والكائن نسخة حقيقية منه |
| حلقة `while` لا تنتهي | المتغير الذي يعتمد عليه الشرط لم يتغير |
| نسيان `return` | الدالة وعدت بإرجاع قيمة ولم ترسلها |
