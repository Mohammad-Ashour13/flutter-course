# شرح كود الجلسة الثانية

شغّل `code/dart_basics_examples.dart`. الملف مقسّم إلى دوال، وكل دالة تمثل محطة من ترتيب الدرس.

## طريقة العرض

1. علّق جميع الاستدعاءات داخل `main`.
2. فعّل استدعاء قسم واحد فقط.
3. اطلب من الطلاب توقع الناتج قبل التشغيل.
4. غيّر قيمة واحدة وأعد التشغيل.
5. نفّذ الخطأ الشائع بصورة مقصودة ثم أصلحه.

## المشروع الجامع

`code/student_club.dart` يجمع الأفكار في برنامج واحد:

- `Student` هو الصف الأساسي.
- `ClubLeader` يرث منه.
- الهوايات `List`.
- الدرجات `Map`.
- `passingGrade` ثابت.
- `hasPassed` دالة تعيد قرارًا.
- الحلقات تطبع البيانات.

لا تعرض المشروع الجامع قبل إنهاء الأمثلة الصغيرة؛ وإلا سيرى الطالب كتلة كود كبيرة بلا معنى.
