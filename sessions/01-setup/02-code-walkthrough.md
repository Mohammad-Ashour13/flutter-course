# أوامر الجلسة الأولى

الأوامر موجودة في `code/setup_commands.md`. لا يُطلب من الطالب حفظها؛ المطلوب أن يفهم وظيفة كل أمر.

1. `git --version`: هل Git متاح؟
2. `flutter --version`: هل النظام يجد Flutter؟
3. `flutter doctor`: ما الأجزاء الجاهزة وما الأجزاء الناقصة؟
4. `flutter devices`: ما الأجهزة التي يمكن تشغيل التطبيق عليها؟
5. `flutter create my_first_app`: إنشاء مشروع جديد.
6. `cd my_first_app`: الدخول إلى مجلد المشروع.
7. `flutter run`: بناء المشروع وتشغيله.

بعد التشغيل:

- اضغط `r` لعمل Hot Reload من الطرفية.
- اضغط `R` لعمل Hot Restart.
- اضغط `q` لإيقاف التشغيل.

اكتب أمرًا واحدًا في كل مرة وانتظر النتيجة. إذا ظهر خطأ، اقرأ أول سطر واضح وآخر سطر قبل إعادة المحاولة.
