# نفّذ الأوامر بالتسلسل

```bash
git --version
flutter --version
flutter doctor
flutter devices
flutter create my_first_app
cd my_first_app
flutter run
```

## أوامر مساعدة

```bash
flutter doctor -v
flutter emulators
flutter pub get
```

لا تنسخ أي أمر من رسالة خطأ عشوائية من الإنترنت دون فهمه أو عرضه على المدرّس.
