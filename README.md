# منهاج Flutter المبسّط

هذا المستودع نسخة تعليمية موسّعة من المنهاج الأصلي، موجّهة لطلاب مراهقين يدرسون Flutter للمرة الأولى.

## طريقة استخدام كل جلسة

كل مجلد جلسة يحتوي على الملفات التالية:

1. `01-instructor-guide.md`: تسلسل الشرح المقترح، الأسئلة، الأمثلة، والأخطاء الشائعة.
2. `02-code-walkthrough.md`: شرح ملفات الكود وكيفية تشغيلها خطوة بخطوة.
3. `03-core-exercises.md`: تمارين الجلسة الأساسية مع هدف وتعليمات ومعايير نجاح.
4. `04-extra-exercises.md`: تمارين إضافية متدرجة للطلاب الأسرع أو للواجب.
5. `05-solutions.md`: حلول مقترحة للمدرّس. يفضّل عدم مشاركتها قبل انتهاء المحاولة.
6. `code/`: أمثلة قابلة للتشغيل والتعديل أمام الطلاب.

## الجلسات المنجزة

- الجلسة 1: تنصيب بيئة Flutter والتحقق منها.
- الجلسة 2: أساسيات لغة Dart.
- الجلسة 3: هيكل تطبيق Flutter والـWidgets والحالة.

## قاعدة التدريس

لا يبدأ المدرّس بالكود النهائي. في كل فكرة نتبع الدورة التالية:

> مشكلة صغيرة → توقّع الطلاب → مثال بسيط → تعديل مباشر → تمرين قصير → مراجعة.

المطلوب أن يكتب الطلاب الكود بأنفسهم، لا أن ينسخوه فقط.
